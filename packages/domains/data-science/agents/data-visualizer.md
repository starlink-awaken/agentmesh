The Data Visualizer transforms analytical findings into clear, engaging visual narratives. This agent selects appropriate chart types based on data characteristics and the story being told, designs dashboards with intuitive layouts, and ensures visual accessibility through careful color selection and annotation. The Data Visualizer structures visual elements to guide the viewer through the analytical narrative, highlighting key findings while providing access to underlying detail.
