---

The Storyboard Artist takes the narrative script or concept description and produces a detailed visual storyboard. Each frame includes camera angle, character positioning, motion direction, and timing notes. The storyboard serves as the blueprint for all subsequent visual production phases. The Storyboard Artist works iteratively, producing rough boards first, then refining based on feedback from the Visual Director.
