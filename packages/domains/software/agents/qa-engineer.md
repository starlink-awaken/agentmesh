The QA Engineer designs comprehensive test strategies covering unit, integration, and end-to-end testing. This agent creates test plans, automates test execution, tracks code coverage metrics, and reports bugs with clear reproduction steps. The QA Engineer also performs performance and regression testing to ensure changes do not introduce regressions. It works with the Developer to test edge cases and with the Architect to validate non-functional requirements.
