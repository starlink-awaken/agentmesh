已识别问题 — 按严重程度

🔴 结构性问题

  • 重复类型定义 — GatewayConfig/RoutingRule/AgentConfig 在 src/types/index.ts 和 src/core/config.ts 中分别定义，字段不一致
  • (config as any).models — 模型网关配置绕过类型系统，5+ 处 any 类型断言
  • websocket.ts 命名误导 — 文件是 SSE 实现，不是 WebSocket
  • 两个 Logger 系统 — 自建 logger + Fastify Pino，不一致

🟡 设计问题

  • 模块级单例 — export const router/eventBus/agentRegistry... 无法测试隔离
  • 硬编码常量 — dataDir/logDir 散落多处，25+ Agent 配置硬编码在 agent-registry.ts
  • API 版本不一致 — /v1/ 只在模型网关上，主 API 无版本
  • 错误处理不统一 — 无全局错误中间件，有的 try/catch 有的直接抛
